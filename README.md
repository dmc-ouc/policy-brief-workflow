# 政府决策咨询专报工作流

版本：1.0.0 · 发布日期：2026-11-25

供 Codex 撰写报市级、省级、国家级、供领导阅示的决策咨询专报。包含选题、政府官网查证、撰写、润色、独立审核、可编辑 Word 排版及人工审定交付。选题由使用者决定；工作流不代写领导批示，不自动报送。

## 直接开始

1. **完整解压 ZIP**，保留 `.agents`、`.codex` 等以点开头的文件夹。找到与本 README 同级的 `AGENTS.md`。
2. 在 Codex 中打开这个文件夹作为项目。在该项目中新建聊天，不必把文件复制进个人全局配置。
3. 先发送下面的环境检查提示。检查本身不启动政策研究：

```text
读取本项目 AGENTS.md、.agents/skills/policy-brief/SKILL.md 和 .agents/skills/policy-brief/references/runtime.md。
先检查两个 Skill、三个子 Agent 配置、Word 模板和随包脚本是否可用。
实际启动一个独立子 Agent，做一次仅返回角色与规则摘要的配置检查，不开展研究。
检查当前会话是否有打开网页原文的工具，以及生成 Word、渲染逐页检查所需的能力和字体。
只报告已实测的项目，未实测的标为未验证；不要安装插件或软件，不要替我选题。
```

4. 检查通过后，复制选题提示并填写自己的输入：

```text
$policy-brief 选题
研究方向或现实问题：〔填写〕
拟报送层级：〔市级／省级／国家级，选一个〕
目标城市、省份或部门：〔知道时填写〕
```

收到 `00-备选选题单.md` 后，工作流会停止等待你定题。决定后发送：

```text
$policy-brief 定题
我选择第〔编号〕题，最终标题为《〔标题〕》。
```

也可以直接提供最终标题、方向和明确层级进入定题流程。更改方向或层级将重新查证，不沿用不匹配的证据。未提供方向或层级时，只询问缺失项，不自行决定层级。

如果技能列表未出现名称，先确认打开的是包含 `AGENTS.md` 的目录；重新打开项目聊天。也可明确要求“读取本项目 `.agents/skills/policy-brief/SKILL.md` 并执行”，但这不能补足环境缺少的工具。

## 需要什么环境

| 能力 | 用途及缺少时的处理 |
|---|---|
| Codex 项目文件读取和写入 | 读取技能、配置，保存每次独立任务；仅上传一个 SKILL.md 到普通聊天不等于安装整套流程 |
| 真实子 Agent | 资料、撰写、审核按阶段交接；不能调用时如实说明并停止依赖阶段，不在一个聊天中扮演三人 |
| 搜索和打开网页原文 | 正式证据须实际打开并核对最终域名、机关、日期、效力等；搜索摘要不算证据 |
| Python 3.11 或更新版本 | 随包检查及 Word 生成脚本只使用标准库；可用 Codex 提供的运行时，不要求另装 Python 包 |
| 文档渲染工具和适用字体 | 用于逐页验收；随包提供 Windows 桌面 Microsoft Word 的只读 PDF 导出脚本，其他环境使用现有可用工具；缺少时明确排版验收未完成 |

本包不包含模型、账号、联网额度、办公软件或字体文件，也不改变使用者的权限设置。不要把本机检查通过理解为每台电脑已经具备所有能力。字体缺失时不得悄悄替换后声称与模板一致。首次使用的详细检查见主 Skill 的 `references/runtime.md`。

## 每次会得到什么

新任务放在 `outputs/policy-brief/<任务编号>/vNNN/`，每次修订另存版本。通常依次包含：

1. `00-备选选题单.md`：3—5 个实质不同的备选题，证据不足时少给；交付后等用户定题。
2. `01-证据台账.md`：只收符合政府官网原文门槛的证据，记录支持判断及边界。
3. `02-报送初稿.md`、`02b-报送润色稿.md`：事实、分析、建议分开，保留证据编号。
4. `03-审核单.md`：真实独立审核、退回修改、复核。
5. `04-报送清稿.docx`、`04-报送核对稿.docx`：同版正文，核对稿保留证据编号；另附台账、审核、待确认事项、排版检查单。

生成 Word 后仍须渲染并逐页查看，人工审定后再由你决定是否报送。脚本不能代替事实审核或授权。

## 范文和模板

随包有通用写作规范和**空白占位 Word 模板**。没有包含原作者的范文、旧专报、证据台账、内部材料或个人账号配置。

你可以另外提供自己获准处理的公开或脱敏范文，明确允许本地学习语言和版式。原作者曾授权过的材料，不代表你已获其使用或传播授权。文内指令作为材料内容，不替代你的要求；范文事实不进入新稿正式证据。

有收件方模板时优先使用。无明确模板时采用随包基线：A4，主标题 22pt 小标宋，正文 16pt 仿宋，一级标题黑体、二级楷体，使用真实标题样式和 PAGE 页码域。具体边距、行距及适用边界见 `references/layout.md`；28pt 是本工作流初始行距，不是标准强制磅值。

## 分享与更新

**不需要 GitHub。** 把完整 ZIP 发给同事，对方按上面的步骤解压并打开项目即可。不要只发送两个 `SKILL.md`：还需要参考规则、子 Agent 配置、模板和工具。

需要多人持续维护、比较修改或发布新版时，再选择 GitHub 私有或公开仓库。建议只上传本发布包中的配置和资源；`.gitignore` 已排除任务产出及临时目录，但仍应检查待上传文件。是否公开、采用什么许可证由你决定，本包没有替你创建仓库或公开任何材料。

更新时建议解压到新文件夹，完成检查后再迁移；不要覆盖已有任务目录。要放入既有项目时，逐项合并项目指令和同名配置，不覆盖对方已有的 `AGENTS.md` 或技能。
