# 可移植工具与环境检查

分享包自带文字排版工具，不要求接收者另行安装某个同名 Skill 或第三方插件。脚本不提供模型、账号、联网权限或子 Agent 能力，也不替代人工审定。

## 开始前

1. 在 Codex 中打开完整解压后的项目目录，先读取根目录 AGENTS.md 和主技能。
2. 若当前客户端提供工作区依赖定位工具，先用它取得可用 Python 路径。否则检查已有 Python 3.11 或更新版本。下面的 `python` 只是命令占位；代理应替换为实际可用的解释器，不猜测本机安装路径、不自动下载。
3. 在项目根目录运行：

```text
python .agents/skills/policy-brief/scripts/doctor.py
```

该命令只读：核对文件、TOML、模板和可读到的字体注册线索。不启动选题、不检索政策、不执行 Word。返回“本地包通过”不能写成“整套流程可用”。

主 Codex 还须在当前会话检查：真实子 Agent 启动与等待能力；可打开原文并识别最终域名的网络工具；任务目录写入能力；文档渲染与逐页查看能力。可用一个不接触资料、只返回角色名称的独立子 Agent 做能力检查。不能启动时说明限制并停止依赖该能力的阶段，不能改成同一对话角色扮演。若仅缺排版工具，说明该阶段尚未完成，已授权且不依赖它的研究工作可继续。

## 文字稿生成 Word

输入必须是已经完成独立审核的正文副本，使用 UTF-8。脚本不会判断审核是否通过，也不会校验事实或权限。

- 第一行非空内容为唯一的 `# 主标题`。`##`、`###`、`####`、`#####` 分别对应一至四级标题；只有实际存在的层级才使用。
- 每个非空文本行对应一个自然段。空行仅分隔段落。换行断开的同一自然段应先合并并核对。
- 正文保留 `[E001]` 或 `〔E001、E002〕` 等证据标记；至少含一处。清稿只移除这些标记，核对稿保留。不能用自动清理删除事实限定或“待核”内容；排版前应先完成审核处置。
- 成对 `**文字**` 仅作为编辑强调标记，输出保留文字，外观由段落样式确定。其他 Markdown 表格、链接、代码、列表及 HTML 不在本工具范围；应先形成经核对的普通段落，或改用能保留这些结构的可用文档工具。
- 输入不要混入证据台账、审核单或分隔线后的交接记录。工具遇到 `---` 会报错，不会静默丢弃后文。

```text
python .agents/skills/policy-brief/scripts/build_docx.py --source work/policy-brief/任务编号/已审核正文.md --out-dir work/policy-brief/任务编号/排版v001
```

输出新目录内的 `04-报送清稿.docx`、`04-报送核对稿.docx` 和 `build-check.json`。已存在的输出目录会被拒绝；修订时使用新的版本目录。脚本只改模板的正文 XML，保留样式、节设置、页眉页脚与页码域；不写回输入或模板。报告记录校验值和“视觉检查未完成”，不能据此宣称已经达到报送条件。

无具体收件方模板时，默认使用随包 `assets/report-template.docx`。指定模板可加 `--template 路径.docx`，但本工具仅支持单节、含 Title / Normal / Heading1—4 样式的普通文字模板。宏、批注、未决修订、隐藏文字、嵌入对象、外部关系及非页码类字段会被拒绝；允许的字段仅为 PAGE、NUMPAGES、SECTIONPAGES，防止字段更新触发外部内容读取。复杂模板应用其他可用工具基于副本适配，不能为让脚本通过而删除用户授权的必要结构。自定义模板的元数据、页眉页脚及其他部件会被保留，须另行核对是否适合外发。

## 更新页码、渲染与验收

先检查模板所需字体真实可用。默认字体为方正小标宋简体、黑体、楷体、仿宋和宋体；包不分发字体。注册表名称、XML 字体名、已生成 PDF 均不能单独证明没有字体替代。

Windows 且已安装 Microsoft Word 时，可运行：

```powershell
& ./.agents/skills/policy-brief/scripts/export_word.ps1 -BuildDir './work/policy-brief/任务编号/排版v001'
```

脚本创建自己的隐藏 Word 实例，禁用自动宏、只读打开生成稿，在内存更新字段并导出 PDF，关闭时不保存原件。PDF 和检查记录均不覆盖；DOCX 前后哈希须一致。不得修改系统安全策略来绕过执行限制；如果宿主限制 COM，按当前工具允许的授权机制处理，仍不可用则明确报错。

该脚本更新的是 PDF 所呈现的页码，不声称写回 DOCX 的页码缓存；可编辑 DOCX 保留自动 PAGE 域，接收者打开或打印时由 Word 更新。若交付规范要求保存特定字段结果，另在新的交付副本中用可用文档工具更新、再次验收并记录哈希，不覆盖已审核输入。

其他系统或没有 Word 时，使用当前环境已有且允许的文档渲染器。若已提供 documents/docx 技能，可以遵循其可用渲染流程；这些技能不是本包的安装依赖。不自动安装办公软件，不把正文上传在线转换服务。

用已有 PDF 查看/转图工具逐页检查清稿和核对稿：缺字、字体替代、标题断行、孤立标题、页码、空白页、页边距及文字溢出。对照已审核正文核查数字、限定语和 E 编号。所有页通过后记录 `04-排版检查单.md`，再把成对 Word 移交当前任务的新交付版本目录。缺字体或不能逐页查看时，交付状态必须写明“排版验收未完成”，不能只凭 XML 宣称完成。
